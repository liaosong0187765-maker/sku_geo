Canonical Source Passport

A serious idea needs a source page before it needs more posts

Professional creators should publish one canonical source page for each serious idea, then distribute platform variants that point back to that source.

Source text

Most expert posts are optimized for feeds. Feeds are good for reach, but weak for memory. A useful idea needs a stable source URL, a clear author, a version, evidence, limitations, and a machine-readable summary.

A Source Passport makes the original idea durable before it gets remixed across X, LinkedIn, WeChat, and Zhihu. The platform posts become distribution copies, not the root source.

This matters for AI retrieval because answer engines need stable pages with clear claims, supporting evidence, and citation hints. If the idea only lives inside short social posts, AI systems may summarize it without attribution or cite a copied version instead of the creator.

The practical workflow is simple:

  • Write the original idea once.
  • Generate the canonical source page and AI markdown pack.
  • Generate platform variants with the same source anchor.
  • Save manual publish URLs after posting.
  • Monitor whether AI responses cite the source URL or merely mention the topic.
  • Revise the source when AI fails to understand or attribute it.

Claim-evidence map

  • A canonical source page is more durable than a platform post.
    The source page has a stable URL, version, hash, schema, sitemap entry, and AI-readable markdown.
  • Platform variants should distribute the idea without becoming the root citation target.
    Each variant includes the same visible source anchor pointing back to the canonical URL.
  • AI retrieval monitoring should score recoverability, not vanity traffic.
    The monitor checks whether a response names the creator, cites the canonical URL, mentions the hash, and preserves the claim-evidence map.

Evidence notes

  • The MVP generates canonical HTML and markdown from the same Source Passport object.
  • The MVP generates X, LinkedIn, WeChat, and Zhihu drafts with visible source anchors.
  • The MVP records manual publication URLs and compares monitor responses against the canonical URL.

Limitations

  • AI citation cannot be guaranteed by source markup alone.
  • Closed social platforms may hide or rewrite source links.
  • The first monitor is a local response analyzer, not a live AI search integration.
