# Platform Templates

These templates keep the same source contract across channels:

- `CID` is the stable content identity.
- `Canonical URL` is the source of truth.
- `Gateway URL` is the short link that resolves back to the source.
- `Source Passport` is the visible fingerprint.

Keep the placeholders intact unless you are filling them with real values.
The platform-specific files below are intentionally plain Markdown so they can
be copied into an editor, CMS, or social draft with minimal cleanup.
